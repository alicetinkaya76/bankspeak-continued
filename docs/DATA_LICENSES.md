# Data terms

- **World Bank Documents & Reports**: official public disclosure repository (Access to
  Information Policy), documents 1946–present. API is public and unauthenticated.
  Most WB-published content is CC BY 3.0 IGO; individual documents may carry their own
  notices — the manifest records `pdfurl`/`txturl` and we cite per document. We store
  derived features and hashes in the repo; raw texts stay local (`data/` is gitignored).
- **Attribution string** (reports/paper): "Contains public World Bank documents retrieved
  via the Documents & Reports API (search.worldbank.org/api/v3/wds), accessed <date>."
- **Pamphlet 9 series data**: published figures in Moretti & Pestre (2015) are used only
  as a replication check target (re-measured from primary documents, not copied).
- **IMF comparator (planned)**: IMF eLibrary/Archives terms differ; s09 documents the
  access route before any download happens.
